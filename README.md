# PHP toy Store Management

## Tech stack

- PHP
- MySQL

## Contents

- `addToy.php`
- `adminDashboard.php`
- `commandToy.php`
- `customerDashboard.php`
- `dbConfig.php`
- `formFunctions.php`
- `index.php`
- `login.php`
- `updateToy.php`

## How to run

```bash
php -S localhost:8000
```

Then open `http://localhost:8000/` in a browser.

Create the MySQL database first and put your own connection settings in `dbConfig.php`.
